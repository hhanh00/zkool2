Memo plugins and a choice of accounts when recovering from the Cloud Vault.

*Released 19 June 2026.*

## Memo plugins

Zkool can run plugins, small scripts in the Rhai language, that turn structured memos into tables. A plugin registers the four byte prefixes it handles; a memo that starts with one of them is passed to the plugin and shown as the table of numbers, strings, dates and links the plugin returns. Plugins are installed from a URL on the Plugins page of Settings, where they can be turned on and off or removed. They are kept in the database, and they run in a sandbox with no access to the file system or the network.

## Also

- Recovering from the Cloud Vault lets you choose which accounts to recover.
- The settings bar is shown even when the account list is empty.
- GraphQL: the transparent address scan limit is an optional parameter.
