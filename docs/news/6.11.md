The first coin voting, authorization for the GraphQL server, and a progress bar for scans.

*Released 9 March 2026 as 6.11.0, last patch 6.11.4 on 24 March 2026.*

## Coin voting

A first version of coin weighted voting: the wallet fetches an election from a vote server, scans its notes to compute its voting power, delegates, fills a ballot and submits it, and synchronizes with the voting chain. The election data can be deleted from the wallet. This version was removed in 6.16 and voting was rebuilt from 6.27; see the [Voting](../vote/overview.md) section for the current one.

## GraphQL authorization

The `zkool_graphql` server authorizes requests with JWT tokens. A token carries a read or a write scope, and an admin token can run any command. See the [GraphQL API](../graphql/api.md) section.

## Also

- Scanning transparent addresses shows a progress bar.
- "Auto Fetch Market Price" updates the exchange rate on its own.
- The selected account is remembered between restarts.
- A transaction's account can be updated.
- The patch releases fixed the database password escaping, the voting Next button, the default transaction expiry of 40 blocks, and a synchronization notification that appeared while the app was in the background.
