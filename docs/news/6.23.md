A smaller download and a friendlier database manager.

*Released 2 July 2026.*

## Sapling parameters on demand

The Sapling proving parameters are no longer bundled with the app, which makes the download about 49 MB smaller. They are fetched from z.cash the first time a shielded transaction needs them. A row in Settings shows whether they are present and lets you download them ahead of time, and the send page shows the progress while they arrive. The GraphQL server downloads them when it starts.

## Database manager

Tapping a database in the manager lists the accounts it holds, the database opened last is highlighted, and the OK button is gone: pick a database and it opens. See the [Database/Wallet Files](../recipe/database.md) recipe.

## Also

- Changing the database password works on Windows, and the password prompt says what it is for.
- Fetch Tx Prices reports its progress, how many prices it fetched, and any server error.
