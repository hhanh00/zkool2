Private lookups for voting and a handful of fixes.

*Released 8 April 2026 as 6.13.5.*

## Voting

The voting feature fetches its data with private information retrieval (PIR), so the vote server does not learn which notes the wallet asks about. A Quit election button clears an election from the wallet, and fetching and importing an election is one atomic step. Underneath, the note witnesses can be rewound and their authentication path computed at an earlier position, which the voting snapshot needs.

## Also

- Mempool transactions show more information.
- Changing the database password escapes the password correctly.
- The amount field refreshes properly.
- Creating a Ledger account works again.
- 32-bit Android builds are dropped.
